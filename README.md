# 修仙者 Token 消耗统计（xiuxiu-token-cultivator）

一个 DeepSeek Harness（DSH）动态 Cordis 插件，在页面右下角显示一个修仙主题的像素角色，实时统计全局累计 token 消耗，并按消耗量推进修仙境界。

## 效果

- 右下角 120px 透明背景像素角色，头顶显示称号（如「炼气三层」「金丹中期」）与实时 token 数
- **三种状态**：
  - 静止：无 token 产出，角色轻微呼吸
  - 工作：模型流式产出时，18 个发光粒子从四周向角色体内汇聚 + 金色呼吸辉光 + 角色浮动
  - 突破：跨大境界时金光渡劫动画，换衣服配色
- **token 增长特效**：每次模型调用结算时 `+XXXX` 上漂 → 停顿 2s → 爆炸成 24 个粒子拖尾飞向角色消失
- 悬停显示修为进度条与「距下一阶」；点击收起/展开

## 领域设定

| 概念 | 含义 |
| --- | --- |
| 修为 | 全局累计 token 消耗（输入 + 输出 + 缓存），只增不减 |
| 境界 | 九阶：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 |
| 子层次 | 炼气十二层；筑基初/中/后期；金丹~渡劫各初/中/后期（共 36 档） |
| 突破 | 修为跨大境界边界时触发（一次跨多阶直达最终境界） |

大境界阈值（指数递增）：炼气 0 → 筑基 10 万 → 金丹 50 万 → 元婴 200 万 → 化神 1000 万 → 炼虚 5000 万 → 合体 2 亿 → 大乘 10 亿 → 渡劫 50 亿。子层阈值在每个大境界区间内指数递增（越接近突破越慢）。

## 安装使用

这是一个**动态 Cordis 插件**，源码是 `host.js` / `client.js` 两个函数体。在 DSH 中通过 `cordis_define` 提交（Host 代码填 `code.host`，Client 代码填 `code.client`），再 `cordis_run` 激活。

> 注意：文件里的代码是「函数体」——即 `return { apply(ctx) {...} }` 这一整段。提交时不要额外包一层 `function`。

## 替换角色

1. 准备一张**透明背景 PNG**（建议 200×200 或 256×256，主体居中）
2. 命名为 `1.png`，放到 Host 可访问的路径（见 `host.js` 里 `loadSprite` 的候选路径）
3. 重启插件（stop 后再 run）即可，无需改代码

## 调参指南

| 想调什么 | 位置 |
| --- | --- |
| 境界阈值 | `host.js` 里 `REALMS` 数组的 `threshold` |
| 子层递增速率 | `host.js` 里 `SUB_Q`（现 1.3） |
| 九阶配色滤镜 | `client.js` 里 `FILTERS` 数组 |
| 工作粒子数/汇聚半径 | `client.js` 里 `PARTICLES`（N=18，radius 62–87px） |
| 爆炸粒子数/散射 | `client.js` 里 `BURST_PARTICLES`（N=24，r 22–38px） |
| 上漂高度/停顿时长 | `client.js` 里 `xiuxiu-gain-float` 关键帧（-198px，30%~92% 停顿） |
| 小人显示尺寸 | `client.js` 里 `.xiuxiu-figure`（现 120px） |

## 已知边界

- 修为从 0 开始，不回填插件激活前的历史消耗
- 九阶换色是 `hue-rotate` 整图变色，若角色肤色与衣服接近会一起被带偏；要精确换装需改「9 张图」方案
- 修为持久化到工作区 `.xiuxiu-cultivation.json`，重启进程后据此续算
